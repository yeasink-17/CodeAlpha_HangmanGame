# Hangman Game 🎮

A simple text-based Hangman game built in Python as part of the **CodeAlpha Python Programming Internship** (Task 1).

## How to Play
- The computer picks a random word from a list of 5 words.
- Guess the word one letter at a time.
- You can make up to 6 wrong guesses.
- Guess all the letters before you run out of chances to win!

## Features
- Random word selection
- Shows guessed letters and blanks (e.g. `_ a _ d _ _`)
- Tracks wrong guesses left
- Rejects invalid input (numbers, multiple letters)
- Warns if you repeat a letter

## How to Run
1. Install Python 3
2. Run: `python hangman.py`

## Concepts Used
`random`, `while` loop, `if-else`, strings, lists
